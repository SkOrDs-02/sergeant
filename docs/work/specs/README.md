# Активні спеки

> **Last touched:** 2026-09-11 by @claude. **Next review:** 2027-04-10.
> **Status:** Active
> **Spec-lint:** skip — каталог-індекс, а не фічева спека.

Це єдиний каталог активної фічевої роботи. Кожна спека описує проблему, мету,
межі, acceptance criteria та перевірку. Шаблон — [`TEMPLATE.md`](./TEMPLATE.md).

Відкриті спеки потрапляють до автогенерованого [дашборда роботи](../../open-work.md).
Після завершення outcome та merge evidence фіксуються в каноні, а локальна
спека прибирається з active checkout; історію залишаємо в Git або ADR.

Під час міграції сюди перенесено активні матеріали з колишніх
`work/specs`, а legacy archive-дерева не розширюються.
