## Перевірені справні шляхи

RootLayout ліниво монтує всі чотири boot-кластери незалежно від маршруту. Nutrition/Fizruk/Routine не чекають входу в модуль для хмарного pull: AnonymousDataMigrationProvider запускає reader і writer для автентизованого користувача, включно з відкладеним переносом. `refreshCachesAfterPull` перечитує потрібні модулі й повідомляє їхні gate-и; для Рутини `emitRoutineStorage` уже повідомляє Hub. Повторно змінювати sync-протокол або створювати окремі запити на кожній картці не потрібно. Ручний cloud refresh уже викликає справжній `pullOnce`.
