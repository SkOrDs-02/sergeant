## Закриття v3.1

Шість PR закрили всі позиції інвентарю А1-Е4; позначка на кожну - [`2026-10-18-design-v3-1-inventory.md`](../audits/2026-10-18-design-v3-1-inventory.md) § Закриття. Мета спеки по пунктах: (1) один прийом стану й рівня дії - `ChoiceGroup`, `variant="text"`, шеврон; (2) перемикач модулів у шапці з PR1; (3) свотч категорії з PR3; (4) повторне знімання тим самим сценарієм, тепер у репо; (5) гейти: `nativeChoice`, `textStateLabel`, `capsFormLabel` = 0 і заборонені `ZERO_ONLY_METRICS`; (6) кадри в обох темах, бюджети нижче.

Відхилення PR1-PR5 власник прийняв 2026-10-23 (§ Рішення власника за відхиленнями вище). Відхилення PR6 В4 (значення лише в рядках з одним станом) власник теж прийняв 2026-10-23: у решти груп набір незалежних налаштувань без одного стану, зведення для них було б новою продуктовою логікою.

**Після PR6 (2026-10-23), п. 7 рішень.** `ChoiceGroup` отримав колбек `onDeselect`: повторний тап по обраній опції знімає вибір. Окремий колбек, а не `allowDeselect` з `onChange(null)`: обʼєднання типів `onChange` ламало виведення параметра в усіх наявних викликах (`tsc`: implicit any у 12 місцях).
