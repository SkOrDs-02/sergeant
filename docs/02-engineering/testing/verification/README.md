# Повторювана верифікація

> **Last validated:** 2026-09-05 by Codex. **Next review:** 2026-12-05.
> **Status:** Active

Це постійна бібліотека перевірок. Результати конкретних прогонів, докази та реєстр знахідок живуть у [трекері](../../../90-work/audits/verification/README.md). Перед роботою агент обирає suite й mode через `pnpm verification list`; не копіює старий чеклист у новий документ.

Поточне покриття, пілот і залишок описані у [стані реалізації](./implementation-status.md). Перед живим прогоном прочитай [локальне середовище та Docker-нюанси](./local-environment.md); кореневий env не є локальною конфігурацією БД.

## Правила для сесії

1. Прочитай картку сценарію та її `pitfalls`, підготуй вказаний профіль за [profiles.md](./profiles.md).
2. Створи прогін з metadata, виконуй сценарії й записуй кожну спробу відразу. `pass` або `fail` без доказу не є результатом.
3. Новий пристрій sync — свіжий логін; Playwright `storageState` переносить `origin_device_id`, але не локальну SQLite.
4. Знахідку заведи або посилься на наявний ID. PR переводить її тільки в `fixed-pending-verification`; `verified` дає лише live pass-спроба.
5. Наприкінці залиш `handoff.md`: що пройдено, стан профілів, блокери, точний наступний крок і корисні нюанси.

## Комплекти

| ID           | Комплект                        | Коли запускати                             |
| ------------ | ------------------------------- | ------------------------------------------ |
| `journeys`   | маршрути та користувацькі шляхи | зміна навігації, auth, тарифів або екранів |
| `logic`      | логіка й розрахунки             | доменна поведінка, дати, суми, агрегати    |
| `ai`         | HubChat, tools, coach, digest   | зміна AI-шару або моделі                   |
| `experience` | візуал, a11y, тексти, антислоп  | UI/UX або copy                             |
| `data`       | API, sync, offline, інтеграції  | сервер, sync, billing, зовнішні дані       |
| `technical`  | регресійні лейни й performance  | перед релізом або після інфра-змін         |

Канонічні картки й машина-читаний каталог: [catalog.json](./catalog.json). Адреси й compatibility probes: [routes.md](./routes.md). Джерела очікувань: продуктові канони, ADR-0078, [anti-slop strategy](../../../05-design/design/anti-slop-strategy.md), існуючі E2E й eval-команди.
