# Empty states

> **Last touched:** 2026-10-18 by @Skords-01. **Next review:** 2027-04-18.
> **Status:** Active

> **Аудиторія:** усі, хто пише UI у `apps/web`.
> **Ціль:** порожній стан пояснює, чого ще немає, і дає один доречний наступний крок.

У вебі є два компоненти з різними ролями:

- `<ModuleEmptyState>` для першого порожнього стану великої модульної поверхні. Він показує компактну статичну ілюстрацію, короткий опис і не більше однієї дії.
- `<EmptyState>` для фільтрів, підсекцій та інших локальних списків. Він показує факт і, за потреби, одну дію. Опис лишається доступним скрінрідеру, якщо `showDescription` не ввімкнено явно.

## Tier 1: модульний first run

Використовуйте `<ModuleEmptyState>`, коли людина ще не створила головний тип даних модуля: операцію, тренування, звичку або прийом їжі.

```tsx
<ModuleEmptyState
  module="routine"
  title="Звичок ще немає"
  description="Створи одну звичку, щоб почати серію."
  onAction={openCreateHabit}
  actionLabel="Створити звичку"
/>
```

Правила:

- Ілюстрація 56 або 64 px, лінійна, статична, у кольорі модуля лише для смислового акценту.
- Заголовок називає стан. Опис одним коротким реченням пояснює, як тут зʼявляться дані.
- Дія веде у вже наявний канонічний сценарій створення. Порожній стан не створює паралельний шлях.
- Якщо глобальна дія вже постійно видима, не дублюйте її. Наприклад, у Фініку лишається глобальна кнопка «Додати».
- Пошук, сортування та підказки про керування списком ховаються, доки самого списку немає.

## Tier 2: локальний список або результат фільтра

Використовуйте `<EmptyState compact>`, коли решта екрана вже має зміст, а порожня лише одна секція чи результат пошуку.

```tsx
<EmptyState
  compact
  title="Нічого не знайшов"
  description="Спробуй інший запит."
  action={
    <Button variant="outline" onClick={clearSearch}>
      Скинути пошук
    </Button>
  }
/>
```

Тут ілюстрація не потрібна. Кнопка має усувати саме причину порожнього результату. Якщо потрібна довга інструкція, це вже не порожній стан.

## Tier 3: один рядок

Для mini-stat, легенди графіка або вузької підсекції достатньо одного тихого рядка:

```tsx
<p className="text-style-caption text-muted">Поки що порожньо</p>
```

Без ілюстрації та кнопки. Якщо потрібна дія, переходьте до Tier 2.

## Як обрати tier

| Поверхня                                    | Tier |
| ------------------------------------------- | ---- |
| Головний список модуля без жодного запису   | 1    |
| Порожній місяць, але записи в інші місяці є | 2    |
| Результат пошуку без збігів                 | 2    |
| Порожня картка всередині заповненого екрана | 2    |
| Mini-stat або коротка підсекція             | 3    |

## Копія

- Українська, форма «ти».
- Заголовок повідомляє факт: «Тренувань ще немає».
- Опис називає конкретний шлях або результат: «Завершене тренування зʼявиться тут».
- Кнопка в інфінітиві: «Почати тренування», «Створити звичку», «Скинути пошук».
- Без риторичних запитань, обіцянок «правди», рекламних вступів і довгого тире.
- Не повторюйте заголовок в описі й не пояснюйте очевидне на кшталт «Тут поки порожньо».

## Доступність

- Контейнер має `role="status"`, `aria-live="polite"` і `aria-atomic="true"`.
- Ілюстрація декоративна та прихована через `aria-hidden`.
- Дія не перехоплює фокус під час монтування.
- Кнопка зберігає видимий `focus-visible` стан і мінімальну touch-зону 44 px.

## Антипатерни

- Велика ілюстрація у маленькій картці.
- Друга кнопка з тією самою дією поруч із глобальною CTA.
- Пошук або сортування над порожнім списком.
- Однаковий first-run стан для повністю порожнього модуля й тимчасово порожнього фільтра.
- Анімація заради руху або декоративні частинки.

## Перевірка

Для змін Tier 1 перевіряйте світлу й темну тему на ширині 390 px. У кадрі мають бути видимі заголовок секції, порожній стан, одна дія або глобальна CTA та нижня навігація. Опис не повинен переноситися більше ніж на три рядки.
