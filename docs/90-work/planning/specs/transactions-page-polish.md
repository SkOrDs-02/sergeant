## 1. Чіпси-зведення → функціональні фільтри (рішення зафіксоване)

Чіпси категорій нагорі сторінки (знайди поточний компонент — грепни рендер чіпів над списком у `Transactions.tsx`/поруч) перестають бути «декоративним дублем аналітики»:

- Тап по чіпу категорії = фільтр списку по цій категорії (toggle; повторний тап знімає). Інтегруй з наявним механізмом фільтрів (`useTransactionFilters.ts`, `categoryFilter` вже існує в `FinykApp.tsx` — реюзни його, не заводь другий стан).
- Активний чіп — виражений стан (стиль дизайн-системи, без емодзі в лейблах).
- Без емодзі, типографічна шкала, focus-visible, ≥44px touch target.
- Якщо поточні чіпи показують суми — суми можна лишити як вторинний текст у чіпі.

## 2. Кредитні картки: нейтральний чіп + іконка (рішення зафіксоване)

`TxRowMetaChips.tsx` (та `accountVisual.ts`, якщо задіяний): чіп картки ЗАВЖДИ нейтральний (`bg-panelHi`), червоне забарвлення для кредиток прибрати. Кредитність позначає маленька іконка в чіпі (підбери з наявного набору `Icon` — напр. кредитна картка/стрілка; глянь `apps/web/src/shared/components/ui/Icon.tsx` каталог). Червоний лишається тільки там, де він про борг/суми (Активи, борги) — ті місця не чіпай.

## 3. Аксесуари рядка: фіксований мета-рядок (рішення зафіксоване)

Під описом транзакції — рівно ОДИН мета-рядок зі сталим порядком елементів: **картка · категорія · спліт-маркер · нотатка** (нотатка з #466 — вона вже рендериться під описом; інтегруй у той самий рядок останнім елементом). Правила:

- Порядок незмінний незалежно від наявності елементів — нічого не «зсувається».
- Overflow: рядок обрізається з «…» (CSS truncate на контейнері), без переносу на другий рядок.
- Нічого не стрибає при появі/зникненні елемента (напр. нотатку додали — рядок не змінює висоту).
- Файли: `TxRowMetaChips.tsx`, `TxRow.tsx` — подивись актуальну структуру після #466.

## 4. Блоки по днях: оцінка → полірування (НЕ сліпий редизайн)

Заголовки днів нещодавно оновлені (#460). Скарга founder-а («дешеві, маленькі, незручні») передувала цьому. Тому:

1. Підніми dev server, подивись поточний вигляд згрупованого списку на mobile viewport.
2. Якщо бачиш конкретні слабкості — полірування в межах наявної структури (sticky headers + collapse ЗБЕРЕГТИ): типографіка заголовка дня (semantic text-style ролі), відступи між групами, читабельність підсумку дня, візуальний звʼязок заголовок↔рядки.
3. ЗАБОРОНЕНО: міняти механіку (virtuoso-групування, collapse, sticky) чи перебудовувати на картки-групи — це не узгоджено.
4. У PR — скріншоти до/після; фінальне слово про «стало краще» — за founder-ом на Vercel preview.
