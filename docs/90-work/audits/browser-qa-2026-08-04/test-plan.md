## Мета

Пройти всі доступні шляхи web-апки очима нового та досвідченого користувача, знайти проблемні місця: биті флоу, сирі стани, UX-пастки, консольні/мережеві помилки, непослідовну копію, порушення інваріантів (гроші/дати/touch targets). Результат — пріоритезований список знахідок у `findings.md`. **Фікси — поза скоупом** (окремим рішенням).

## Скоуп

- **In:** apps/web через реальний браузер, повний стек (auth + API + БД), desktop і mobile viewport, 3–5 тестових акаунтів з різними профілями даних.
- **Out:** apps/mobile / mobile-shell (нема емулятора), apps/landing (окрема поверхня), прод-середовище, performance-бенчмарки (є LHCI), написання Playwright-спек.

## Маршрути й області (з router.tsx)

1. Auth lifecycle: `/sign-in` (реєстрація, логін, помилки валідації, logout, повторний логін, сесія після reload).
2. `/welcome` + `/onboarding/*` — перший вхід.
3. `/` — Hub root: картки модулів, dnd, аналітика, порожній/наповнений стани.
4. `/finyk/*` — фінанси: рахунки, транзакції (витрата/дохід), категорії, кредитка, фільтри.
5. `/nutrition/*` — калорії/макро: цілі, лог, меню, штрих-код.
6. `/routine/*` — звички/todo: today, стріки.
7. `/fizruk/*` — тренування.
8. `/insights/*` — звіти/інсайти.
9. `/settings/*` — профіль, пресети, налаштування.
10. Standalone: `/chat` (HubChat), `/pricing`, `/status`, `/design`.
11. Невідомий шлях → 404-поведінка catch-all.

## Обов'язкові критерії (gate на кожен маршрут × акаунт)

1. **Консоль чиста** — жодних нових errors (warnings фіксуємо як P3).
2. **Network** — жодних неочікуваних 4xx/5xx; failed запити = знахідка.
3. **Empty state** — існує, зрозумілий, має action-prompt (не «порожньо»).
4. **Форми** — валідація зрозуміла UA-мовою; подвійний сабміт не дублює запис; скасування працює.
5. **Persistence** — запис видно після reload і повторного логіну; дані не течуть між акаунтами.
6. **Гроші/дати** — суми в копійках рендеряться коректно (великі значення, 1 коп.), день міняється за Europe/Kyiv.
7. **Touch targets** — ≥44×44 на coarse pointer (акаунт E).
8. **Клавіатура/фокус** — інтерактив досяжний Tab-ом, focus-visible видно.
9. **Копія** — UA, `ти`-звертання, без обрізаних/сирих рядків, без англ. плейсхолдерів.
10. **Крос-модульність** — дія в модулі відбивається у Hub/insights, де обіцяно.

## Методика

- Браузер один, дії серіалізовані. Навігація по SPA-лінках; повний reload — лише як окремий тест persistence.
- Кліки семантичні (по ролях/aria), не по пікселях; текст у поля — реальними keystrokes.
- Кожна знахідка → запис у `findings.md` одразу (severity, route, репро, evidence-скріншот у `evidence/`).
- Прогрес трекається в `progress.md` після кожної області.

## Севериті

- **P0** — блокер флоу / втрата даних / крах сторінки.
- **P1** — основний сценарій сильно ускладнений або дані відображаються неправильно.
- **P2** — помітна вада UX/UI, обхідний шлях є.
- **P3** — полірування: копія, консольні warnings, дрібні стилі.
