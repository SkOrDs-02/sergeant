## 3. Хвилі фіксів

Порядок — за співвідношенням «шкода користувачу / вартість правки», не за
severity. Кожна хвиля — окремий PR або два; не змішувати з фічами.

### Хвиля 0 — CI (сьогодні, без продуктових змін)

- ✅ CI-1, CI-3, CI-4 — виправлено цим PR (typecheck + 2 застарілі тести).
- CI-6: додати «Superseded» до словника `lint:initiative-status-sync`;
  `toolEvalJudge.ts` → `env.js`. Без цього `pnpm lint` червоний для всіх.
- CI-5: eager 285,8 kB > 280 — знайти нове eager-ребро (порівняти 77 чанків
  із 73 на 2026-08-07; `cn` 21,5 kB у критичному шляху підозрілий), не
  ратчетити наосліп.
- CI-7: `@critical` pantry-тест ↔ перебудований аркуш «Звідки страва?» —
  або розгортати «З комори» в тесті, або не рендерити чипи у згорнутому стані.
- CI-8: LCP 3,3–3,7 с на трьох із чотирьох LHCI-маршрутів (поріг 3,0) —
  один сигнал із CI-5: критичний шлях підріс; спершу знайти ребро, потім
  міряти знову.
- CI-2: 299 битих внутрішніх посилань (два файли) — механічно.

### Хвиля 1 — блокери (цей тиждень)

- AI-1 → `ToolUseBlockSchema`: `passthrough()`/`caller: z.unknown().optional()`
  - юніт на реальний OpenRouter-блок; разом з AI-5 — refund квитка на
    будь-який не-2xx, виданий ДО виклику upstream.
- SYNC-3 → знайти джерело повторного enqueue (pull-apply → LS/warm cache →

- CALC-4 → звіти при deep-link читають дані до того, як SQLite-кеш готовий;
  гейт: deep-link = SPA на тому самому акаунті (Q3).

## 7. Уроки для наступного прогону

- **`storageState` ≠ новий пристрій** (`accounts.md § 6`): той самий
  `origin_device_id` не отримує власних ops на pull. Двічі виглядало як
  «синк втратив дані».
- **Паралельні свіпи проти одного `vite preview`** дають порожній `#root`
  (6 із ~900) і збої динамічних імпортів — для perf/стабільності потрібен
  окремий прогін без сусідів; для функціональних свіпів це шум, але саме він
  показав UX-3.
- **Сідер має чекати дренажу черги** перед закриттям контексту, інакше
  server-side еталон розходиться з тим, що «бачив» сідер (відмітки Q2/Q5/Q8).
- **Гейти в ланцюжку `&&`** (lint, size-limit після build) мовчать після
  першого червоного кроку — CI-5 і CI-6 знайдені лише тому, що кроки прогнали
  окремо.
