## Як писати знахідку

- **ID** — `<вимір>-<номер>`: `LOG` логіка · `FUN` функціональність · `UX` ·
  `VIS` візуал · `SLOP` анти-слоп · `TXT` текст · `JRN` шлях юзера · `AI` ·
  `CALC` розрахунки · `A11Y` · `PERF` · `SYNC` · `SEC` · `CI` (червоні гейти
  на `main`, знайдені автоматичним базисом). Номер наскрізний у
  межах виміру. ID стабільний: ним називаються коміти й PR.
- **Severity:** `blocker` (втрата даних, білий екран, неможливо завершити
  основний шлях, гроші порахувані неправильно) · `major` (функція не працює
  або бреше, обхід є) · `minor` (працює, але з тертям) · `polish`
  (косметика, копі).
- **Стан:** `описано` → `підтверджено` (відтворено вдруге або іншим акаунтом)
  → `у роботі #PR` → `виправлено #PR` (верифіковано наживо) → `закрито`.
  Окремо: `знято` (помилка виміру, з поясненням) і `рішення власника`
  (продуктова розвилка, чекає вибору).
- **Доказ обовʼязковий:** маршрут, акаунт, кроки, очікуване / реальне,
  консоль або мережа, скріншот (де є), `file:line` кореня, якщо відомий.
  Знахідка без відтворюваних кроків — це спостереження (§ нижче), не баг.
- Не дублювати відкриті знахідки попередніх аудитів — посилатись на них
  (§ «Успадковані відкриті»).

### CI-1 — `web#typecheck` червоний на `main` [major]

**Поверхня:** `pnpm check:typecheck-and-test` на `b16956d` (= `origin/main`).
**Симптом:** `src/modules/finyk/pages/overview/useOverviewData.test.ts(379,11): error TS2740: Type 'Record<string, unknown>' is missing the following properties from type 'Transaction'`.
Turbo зупиняє решту пайплайну, тож `web#test` у тому ж прогоні не виконався.
**Корінь:** коміт `ffbe3c9` (forecast v2, 2026-08-31) додав кейс
«is deterministic across repeated renders», де `mkTx(...)` покладено в `realTx`
без кастингу `as UseOverviewDataParams["mono"]["realTx"]`, який стоїть у всіх
сусідніх кейсах того ж файлу. Урок із `AGENTS.md § Performance budgets`
повторився: мерж до завершення `check` → червоний гейт мовчить на `main`.
**Фікс:** той самий кастинг (одна рядкова правка); `pnpm --filter @sergeant/web typecheck` → 0 помилок.
**Стан:** виправлено цим PR.

**Фікс:** не в цьому PR (не стосується аудиту); окремий `docs(docs)` PR з
`reconcile-doc-drift.md`. Якщо workflow blocking — підняти до major.
**Стан:** описано.
