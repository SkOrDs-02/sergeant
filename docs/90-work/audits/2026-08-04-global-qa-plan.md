# Глобальна браузерна QA: дизайн тестування

> **Last touched:** 2026-08-04 by @Skords-01. **Next review:** 2027-09-11.
> **Status:** Active

Мета: пройти `apps/web` очима **автентифікованих** користувачів — 5 тестових
акаунтів з різними профілями даних — по всіх маршрутах, опціях і відомих
пастках, щоб знайти проблемні місця й сирі моменти. Доповнює попередній прогін
[`web-qa-pre-beta.md`](./web-qa-pre-beta.md) (2026-08-02, анонім + push-контур):
там — анонімний контур, тут — повний обхід із реальними акаунтами та
перевіркою ізоляції даних між ними.

## Скоуп маршрутів (повний обхід)

Джерело: `apps/web/src/core/app/appPaths.ts` + `StandaloneRoutes.tsx`.

1. **Auth-контур:** `/welcome`, `/sign-in` (+ аліаси `/auth`, `/oauth` → redirect), signup, sign-in, невірний пароль, `/reset-password`, `/verify-email`, logout.
2. **Hub root `/`:** картки модулів, bottom-nav, header-меню, notification bell, sync-статус, онбординг-віза.
3. **Фінік:** `/finyk`, `/finyk/budgets`, `/finyk/cards` — CRUD витрат/доходів, бюджети, Monobank-CTA.
4. **Фізрук:** `/fizruk`, `/fizruk/workouts`, `/fizruk/exercise/:id` — тренування, active-workout banner.
5. **Рутина:** `/routine`, `/routine/stats` — звички, виконання/скіп, статистика. ⚠ відомий blocker `hab_<uuid>` із прогону 2026-08-02 — переперевірити стан фіксу.
6. **Nutrition:** `/nutrition` (→ `/nutrition/menu`), `/nutrition/log`, `/nutrition/pantry/shopping`.
7. **AI-шар:** `/chat`, `/assistant`, `/capabilities`, `/coach` — з placeholder-ключем очікуємо чесний 503-UX, не мовчазну смерть.
8. **Аккаунт-шар:** `/profile`, налаштування, memory для ШІ, білінг `/pricing`.
9. **Довідково-юридичний шар:** `/legal/{privacy,terms,cookies,offer}`, `/status`, `/help`, `/design` (DesignShowcase).
10. **Пастки:** невідомі шляхи (`/finykfoo`, `/some-random-bogus-path` → 404-guard), подвійний submit, back/forward-навігація, reload на глибокому маршруті, крос-акаунтна ізоляція даних (A2 не бачить дані A3), logout → доступ до захищених маршрутів.

## Обовʼязкові критерії (gate на кожен маршрут/флоу)

| #   | Критерій                                                                                       |
| --- | ---------------------------------------------------------------------------------------------- |
| 1   | Немає console errors (нові error-рівневі записи = знахідка; відомі warnings фіксуються окремо) |
| 2   | Немає неочікуваних failed network-запитів (4xx/5xx поза контрактними, як-от 503 без AI-ключа)  |
| 3   | Немає blank screen / незловленого ErrorBoundary                                                |
| 4   | Форми: клієнтська валідація працює, помилки — українською, зрозумілі, з action-prompt          |
| 5   | Дані персистяться: створене видно після SPA-навігації геть і назад                             |
| 6   | Ізоляція: дані акаунта X ніколи не видно в акаунті Y (перевірка після перелогіну)              |
| 7   | Empty states: осмислений текст + CTA, не «порожньо» і не skeleton назавжди                     |
| 8   | 404-guard: невідомий шлях дає 404-сторінку, не мовчазний fallback на Hub                       |
| 9   | Touch targets ≥44×44 на coarse pointer (прохід у мобільному viewport)                          |
| 10  | Копірайтинг: UA, `ти`-звертання, без сирих i18n-ключів і англ. плейсхолдерів                   |

Знахідки класифікуються: **blocker / major / minor / polish** + категорія
(functional / data-integrity / ux-copy / a11y / perf / security).

## Методологія

- Браузер — **один**, дії серіалізовані (жодних паралельних браузерних агентів).
- Паралельний read-only трек: Workflow `web-ux-cycle` (fan-out код-діагностика
  за тими самими маршрутами) — його знахідки зливаються у спільний файл.
- Кожна знахідка — з доказом: маршрут, кроки, очікуване/реальне, консоль/мережа,
  скріншот (де можливо), `file:line` де відомий корінь.
- Прогрес трекається у [`2026-08-04-global-qa-progress.md`](./2026-08-04-global-qa-progress.md),
  знахідки — у [`2026-08-04-global-qa-findings.md`](./2026-08-04-global-qa-findings.md).
- Фікси в цьому прогоні не застосовуються (audit-only) — окрім хіба тривіальних
  блокерів самого прогону; все інше — у findings з рекомендаціями.
