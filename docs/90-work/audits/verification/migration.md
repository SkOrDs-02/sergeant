## Правила перенесення й неоднозначності

- Збережено legacyId; namespace розрізняє однакові F/B/числові ID різних аудитів. Для нерозмічених пунктів використано номер секції або явний названий кластер. source — існуючий repo-relative файл; sourceAnchor — пошуковий заголовок/legacy ID, не обіцянка браузерного fragment. Severity unrated означає, що джерело не задає сумісної оцінки; її має встановити тріаж.
- Новіші детальні статуси мають перевагу над давнім планом. Product-audit: перенесено AI-2, CI-8, VIS-2, SLOP-4 та SLOP-3 (summary каже «4», але SLOP-3 має невиконаний залишок у density-спеці). Закриті рядки не імпортовано.
- AI pipeline: B1/B2/B7 закриті; abuse A1/A2/A4/A6 закриті, A9 закритий доказом у pipeline. AI testing: B31/B32/B36/B37/B39/B46 виключено за пізнішим product-audit (B31 завершено SEC-1). B40 та A7 перетинаються; історичні ID збережено, обʼєднання потребує тріажу.
- Global QA: 2–7 виключено як виправлені. 11 і 14 мають fixed-pending-verification за пізнішими UX-1/TXT-6; нового live-доказу немає. W-16/W-31 — кластери: повний session JSON wf_d5f23f12-dbf відсутній. Відоме часткове виправлення навігаційного підпису не закриває весь кластер.
- Browser QA: відкриті F-002/F-006 і F-005 needs-repro. F-001/003/004/007/008/009/010/011 закриті за таблицею виправлень; непідтверджений новий пристрій F-007 не перетворено на окремий дефект. Browser-profile: основні M/B виправлені; перенесено тільки явні залишкові рішення B6/B7.
- Fizruk: старий header/план не враховує хвилі 2–5. Імпортовано два явні залишки після хвилі 5 (двоколонка та wellbeing); демо й retro-workout закриті. Anti-slop: лише F7, інші F закриті §4а. Icons §5 лишає пʼять боргів; F7 перетинається з §5.1/5.2, але має ширший периметр.
- Security: текст навмисно frozen і каже «26 із 50 закрито», не надаючи відповідності всіх 50 ID. Імпортовано ідентифіковані кандидати/кластери з невизначеним станом; open тут вимагає зіставлення з історичним diff і повторної перевірки. Не можна вважати всі ці записи чинними вразливостями або 24 гарантовано відкритими дефектами.
- Orphaned: перенесено проблемні кластери; false-positive/чисті секції виключено. Видалення підписки при account-delete виключено: є пізніша деталізація виправлення. Mono cron і HubChat HTTP залишено як операційний тріаж. Lost-commits: header прямо обмежує відкритий залишок §3; імпортовано 9 елементів §3, давні §2/§4 не відкрито повторно.
- Unification: §1 (28 номерів, 1.5–1.7 зведені в одну картку) та §2 (29) дають 55 записів; 11 свідомих локальностей §3 виключено. Це статичний знімок; пізніші зміни годинників/формул потребують тріажу перед будь-яким фіксом.
- Coverage №2 лишається неоднозначним: таблиця каже частково, але visual/Argos прибрано ADR-0082. №1 знято рішенням, №3–7 закриті; повернення Argos не випливає з імпорту. Юридичні й зовнішні висновки перенесено як історичні питання; оцінки не перевірялися заново.
