# Канонічні деталі операції та глобальний FAB Фініка

> **Last touched:** 2026-07-28 by Codex. **Next review:** 2027-01-27.
> **Status:** Active — implementation ready, PR pending

## Мета

Прибрати конкуренцію між інлайн-іконками та повною формою редагування операції,
а також зробити створення ручної операції доступним незалежно від поточної
сторінки Фініка.

## Продуктові рішення

1. Клік по рядку є єдиною персональною точкою входу в деталі операції.
2. Ручна операція відкриває наявну повну форму: тип, сума, назва, дата й
   категорія редагуються як власні дані користувача.
3. Банківська операція відкриває окрему шторку деталей. Факти банку — сума,
   опис, дата, джерело та рахунок — тільки для читання. У цій самій шторці
   редагуються лише користувацькі оверлеї:
   - категорія;
   - нотатка;
   - розподіл суми між категоріями;
   - «не враховувати у статистиці»;
   - «приховати зі списку».
4. Іконки категорії, розподілу й приховування в рядку списку не є другим
   редактором. Свайп вліво лишається швидкою оборотною дією приховування або
   видалення ручної операції.
5. Checkbox-режим не дублює персональне редагування: він існує тільки для
   пакетної категоризації, приховування та виключення зі статистики.
6. FAB «Додати витрату» показується на Огляді, Операціях, Плануванні,
   Аналітиці та Активах. Під час login overlay він прихований, щоб не
   конкурувати з підключенням банку.

## Дані та інваріанти

- Нової сутності чи storage-key немає: форма використовує наявні
  `txCategories`, `txNotes`, `txSplits`, `hiddenTxIds` і
  `excludedStatTxIds`.
- Банківські поля не перезаписуються локальними значеннями.
- `hiddenTxIds` прибирає операцію зі списку та розрахунків;
  `excludedStatTxIds` лишає її у списку, але прибирає зі статистики.
- Сума розподілу має дорівнювати абсолютній сумі банківської операції;
  незбалансований розподіл не зберігається.
- Категоризація з форми зберігає чинну подію
  `finyk_tx_categorized`; payload не містить користувацьких назв або id
  кастомних категорій.

## Acceptance criteria

- Клік по ручній операції відкриває повну ручну форму.
- Клік по банківській операції відкриває одну шторку з read-only фактами банку
  та всіма пʼятьма користувацькими оверлеями.
- У банківському рядку немає окремих кнопок «Змінити категорію»,
  «Розподілити» або «Приховати».
- В режимі вибору клік по рядку лише змінює checkbox-стан і не відкриває форму.
- FAB доступний на кожній із пʼяти сторінок Фініка й відкриває створення ручної
  операції.
- Keyboard-safe поведінка успадковується від спільного `Sheet`: панель
  зменшується до видимої області, а її body скролиться над клавіатурою.
- Цільові component/integration тести та scoped ESLint проходять без помилок і
  попереджень.
